# 来源与第三方许可

本项目将 [zterm](https://github.com/guhanfei-ai/zterm) 0.4.1 的终端核心移植到 DSH。移植基线为源项目提交 `602f5a215d28c24e9e86356779d105ce2221e964`（仅作来源标识，本工程没有执行 Git 写操作）。

`src/core/` 的 SSH、PTY、JumpServer、终端完成协议、输出缓冲、内置读工具、命令限制、输入协调、主机信任与错误翻译均源自 zterm；DSH 的宿主适配、工具接口、存储和 React 工作台在本项目实现。有效回归测试保留了来源说明，并替换了源项目的 Pi/Electron 适配。

zterm 的原始 MIT 许可保存在随包分发的 `LICENSE`。本项目没有分发源项目的 Electron 应用、模型运行时、用户配置、凭据或 Git 元数据。

## 依赖说明

xterm.js、Fit 和 Search 随客户端打包。ssh2、node-pty、Schemastery 和 TypeBox 作为 npm 依赖安装；各依赖及其传递依赖的原始许可证随各自包分发。React 由 DSH 宿主共享，本项目的生产客户端不打包第二份 React。
